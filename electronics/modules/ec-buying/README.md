## Accuracy and provenance

No reusable STEP, STL, or SCAD model matching these exact boards was found.
KY-009 Fritzing data exists, but it is not a mechanical 3D model. Dimensions
were transcribed from the listing image supplied on 2026-08-09. The horizontal
RGB board dimension is estimated from the header pitch because the listing does
not display a dimension for that variant.

Verify hole positions, component heights, and the estimated board size against
a physical sample before manufacturing an interference-fit enclosure.

## Reference information

- KY-009 is a 5050 SMD RGB module and is commonly documented as approximately
  18.5–19 × 15 mm.
- KY-016 is the through-hole RGB counterpart.
- KY-011 is the two-colour LED module.
- KY-034 is the automatic seven-colour flashing LED module.

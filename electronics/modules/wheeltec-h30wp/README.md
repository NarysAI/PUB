# WHEELTEC H30WP IMU board

Self-contained OpenSCAD reference model of the PCB identified by the project
owner as the WHEELTEC H30WP IMU board.

## Geometry

- PCB envelope: 42.5 x 31.0 x 1.6 mm.
- Four 2.2 mm mounting holes and approximate component, pad, connector, and
  silkscreen placement.
- Canonical source: `wheeltec_h30wp.scad`; no external geometry imports are
  required.

The model was reconstructed from a single top-view photograph and is intended
for visualization, placement, and preliminary clearance work. It is not a
manufacturer mechanical drawing. The published H30WP product specification
describes a 63 x 55 x 24.5 mm waterproof enclosure; this catalog object models
the supplied internal PCB reference, not that enclosure. Verify critical
dimensions and interfaces against physical hardware before manufacturing.

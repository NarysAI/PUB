# Raspberry Pi boards

Each board generation is a separate child package. Use directories such as
`rpi1`, `rpi2`, `rpi3`, `rpi4`, `rpi5`, and `zero`; keep model variants as parts
inside the corresponding package.

Available packages:

- `rpi4/` — Raspberry Pi 4 family.
- `rpi5/` — Raspberry Pi 5 reference board and Active Cooler variant.

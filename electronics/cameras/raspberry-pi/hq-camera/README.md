# Raspberry Pi HQ Camera reference models

Reference models for the Raspberry Pi High Quality Camera, its 6 mm wide-angle lens, and its 16 mm telephoto lens.

The catalog exposes ready-to-use STL models. Their canonical OpenSCAD sources are retained in `sources/`.

Source: [Thingiverse model 4335497](https://www.thingiverse.com/thing:4335497), created by David Crook (`dpc`).

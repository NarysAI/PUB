# USB Type-C male cable connector

AI-readable placement and clearance model of a generic USB Type-C male cable
connector. The mating plug, overmould, strain relief, and a short cable segment
are represented as one catalog object.

## Source and authorship

Visual reference: [USB C (type-c) male connector cable](https://grabcad.com/library/usb-c-type-c-male-connector-cable-1),
uploaded by Omri Datz on 2025-04-26. The source page contains one STEP file named
`USB C Male connector cable.STEP`. Downloading it requires a GrabCAD account and
the page does not provide explicit redistribution terms, so the STEP source is
not included in PUB.

The SCAD model in this package is independently authored for NarysAI from the
public reference render and nominal USB Type-C plug dimensions. The metal shell
uses an `8.25 x 2.40 mm` clearance envelope with a `6.65 mm` exposed length. The
overmould, strain-relief, and cable dimensions are visual estimates and are not
tied to a specific cable manufacturer.

## Intended use and limitations

Use the model for enclosure layout, port-access checks, cable clearance, and
visual assembly previews. Do not use it to manufacture a standards-compliant
plug, contact system, or production mating datum. Contact pads and internal
tongue details are representational.

The optimized STL was generated directly from the self-contained SCAD and was
visually compared with the SCAD render and the GrabCAD reference viewer.

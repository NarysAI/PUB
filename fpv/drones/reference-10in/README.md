# Complete 10-inch FPV drone reference

The complete mechanical assembly available in the supplied STEP, converted to
one self-contained native OpenSCAD model.

## Included

- complete 10-inch tube-frame assembly;
- four reference motors, approximately 35 mm diameter;
- four nominal 10-inch three-blade propellers.

Rendered envelope: approximately 568.27 x 578.73 x 68.35 mm. The SCAD contains
the full assembled tessellation in one polyhedron and uses no external mesh/CAD
import.

This is not a complete flyable bill of materials. The source does not contain a
flight controller, ESCs, camera, VTX, antennas, battery, wiring, or fasteners.
Electrical compatibility, propeller safety, mass properties, thrust, structural
strength, and flight readiness are unverified.

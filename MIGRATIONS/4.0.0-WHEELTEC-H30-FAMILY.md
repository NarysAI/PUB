# WHEELTEC H30 family migration in PUB 4.0.0

## Stable-path mapping

| Previous object | Exact replacement |
| --- | --- |
| `part/electronics/modules/wheeltec-h30wp:wheeltec-h30wp` | `part/electronics/modules/wheeltec-h30:h30-pcb` |

The previous model contains the bare PCB rather than the waterproof H30WP
product. The NarysAI website resolves the previous path as a compatibility
alias; all newly generated links point to the exact H30 PCB variant.

## New variant

`part/electronics/modules/wheeltec-h30:h30-enclosed` is the complete standard
metal-housing sensor variant. Revision 1.1 identifies H30 PCB as the base model
and links the PCB, main housing, separate cover, four cover screws, and four
plastic vibration-isolating screws as exact catalog components.

## Official sources

The H30 PCB and H30 Enclosed identities and envelopes were verified against the
mechanical files linked by the Seeed Studio WHEELTEC IMU documentation and
published in `Seeed-Projects/WHEELTEC-H30-IMU`. The repository did not include
an explicit license for the CAD files, so the package remains
`license_status: unverified`.

# Restore the original XL4015 object

Catalog release: `4.1.5`

The stable object identity
`electronics/power-converters/xl4015:xl4015-step-down-5a-cc-cv` is restored to
its original detailed STEP file:

`electronics/power-converters/xl4015/xl4015-step-down-5a-cc-cv.step`

Release 4.1.4 incorrectly treated the separate GrabCAD `xl4015-1` variant as the
source of this object and replaced the catalog representation with a reconstructed
exterior derived from the original XL4015 geometry. The SCAD/STL files added in
that release are retained temporarily for audit and recovery, but are no longer
declared as representations of the stable object.

`XL4015` and `xl4015-1` must be separate catalog objects. The `xl4015-1` object
may be published only after obtaining its actual source geometry and producing
its own optimized, self-contained SCAD plus generated STL bundle.

# USB-C original-dimension correction (4.5.2)

The stable package and object identity remains unchanged:

`//pub/electronics/connectors/usb/usb-c-male-cable:usb-c-male-cable`

The 4.5.0 geometry was a visual estimate and did not match the linked original
assembly. Release 4.5.2 replaces it with a reconstruction measured in the
GrabCAD STEP viewer. The overall envelope changes from approximately
`63.50 x 12.48 x 8.25 mm` to `48.77 x 10.65 x 5.70 mm`. The incorrect ribbed
boot is replaced by the source model's `5.69 mm` smooth, `4.50 mm` diameter wire
tube, followed by an `18.83 mm`, `3.30 mm` diameter cable segment.

This is a compatible geometry correction: package path, object name, kind,
canonical source type, and public URL remain stable.

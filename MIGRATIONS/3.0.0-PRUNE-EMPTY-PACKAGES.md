# PUB 3.0.0 empty-package cleanup

PUB 3.0.0 intentionally removes five public packages that exposed no usable
part or assembly, including the sketch-only metric-interface package.

- `//pub/electronics/sbcs/raspberrypi/compute-modules`
- `//pub/electronics/sbcs/raspberrypi/microcontrollers`
- `//pub/std/metric/m`
- `//pub/std/metric/nema`
- `//pub/svc/commerce/gobilda`

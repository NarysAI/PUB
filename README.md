# NarysAI PUB

Public monorepository of standard PartCAD packages used by the NarysAI catalog.
The directory layout is the stable PartCAD namespace: `electrical/battery/ego`
maps to `//pub/electrical/battery/ego`.

Files retain their original authorship and licenses. Every imported package has
a `.narys-upstream.yaml` provenance manifest. `license_status: unverified` means
that reuse terms must be checked with the upstream author before redistribution.

The repository is generated by `NarysAI/narys-web/tools/migrate_pub.py`. Changes
intended for an upstream project must be exported without `.narys-*` files.
